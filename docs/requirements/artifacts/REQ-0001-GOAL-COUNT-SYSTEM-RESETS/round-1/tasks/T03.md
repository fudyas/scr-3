# T03 — Recorder core

Depends on T01,T02. Implement LKM lifecycle, SRC capture, module-owned boot guard, pending event, retry scheduler, serialization, clean shutdown. Freeze shared C interfaces first.

Own: kernel Makefile, core/event/guard/cause sources/headers, core tests, `evidence/recorder-core/*`.

DoD: SRC captured once before async storage; raw + decoded flags preserved; unknown remains unknown; no status/control writes; one accepted event per supported boot/reload; failed init recoverable; first event time frozen; retry 1..60 seconds; one worker/pending event; reset cancellation prevents recreation; shutdown drains work; active descriptors pin module; no userspace state authority.

Tests: every init/guard boundary; repeated starts/reloads; unknown/combined flags; retry sequence; count/reset/shutdown interleavings; worker cancel; busy unload; verified-ABI compile. No HW load.
