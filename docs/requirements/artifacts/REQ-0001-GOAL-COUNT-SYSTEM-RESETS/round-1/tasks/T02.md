# T02 — Reversible package skeleton

Depends on T01. Run `./bin/lets sdlc package-init`. Freeze package root. Build package metadata, ownership manifest, durable first-baseline backup, transaction journal, conflict checks, atomic publication, upgrade recovery, pending removal, generic restoration.

Own: package `DEBIAN/*`, lifecycle helpers/tests, `contracts/package-lifecycle.json`, `evidence/package-skeleton/*`. Six destinations: module, Bash frontend, init script, rcS symlink, README, package-test.

DoD: install never loads module; first baseline never overwritten; upgrade keeps resident module/records; failure restores prior payload; removal marker durable before activation disabled; no force unload/reboot; busy unload fails pending; remove/purge restore baseline records/metadata; unrelated paths preserved; overlaps refused; restoration code implements no operational count/reset truth.

Tests: fixture-root install/remove/purge/reinstall/upgrade/failure; interruption at journal boundaries; pre-existing records/metadata; busy unload; conflict/coexistence; unsupported metadata refusal.
